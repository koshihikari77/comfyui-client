# AREA / COUPLE のハマりどころ

## 1. 座標に隙間がある

- 症状: 意図しない領域にベース prompt だけが出る
- 原因: `0〜0.4`, `0.45〜0.6` のように gap がある
- 対処: 0〜1 を隙間なく埋める

## 2. AREA だけで終えている

- 症状: 境界が硬く、不自然な分離になる
- 原因: なじませる COUPLE フェーズが無い
- 対処: `AREA(...):COUPLE(...):TIMING` を基本形にする

## 3. TIMING の意味を取り違える

- 症状: 切り替えが早すぎる / 遅すぎる
- 原因: `step` を割合と整数ステップで混同している
- 対処: まず 0〜1 の比率で考える

## 4. ブロック境界を誤る

- 症状: ある prompt が別領域に食い込む
- 原因: `AND` から次の `AND` / `BREAK` までが 1 ブロックという前提を見落としている
- 対処: 1 ブロック 1 領域として読む

## 5. 人数タグが強すぎる

- 症状: 局所領域の構図が崩れる
- 原因: `1girl` などを最後まで強く残している
- 対処: `[1girl::TIMING]` のように序盤だけ効かせる
